2. FEATURES IMPLEMENTED (VERTICAL SLICE)
--------------------------------------------------------------------------------
A. Event Creation & Management (Officer CRUD)
   - Database Model: Real Event model with fields: title, description,
     date_time (DateTimeField), venue, capacity (PositiveIntegerField),
     created_by (ForeignKey to CustomUser with related_name='created_events'),
     created_at, and updated_at timestamps.
   - Validation & Form: EventForm enforces that scheduled date_time cannot be in
     the past, and capacity must be at least 1 attendee.
   - Views & Endpoints:
     * /events/create/ (event_create): Officer-only view to publish events.
     * /events/<id>/edit/ (event_update): Officer-only view to update event info.
     * /events/<id>/delete/ (event_delete): Officer confirmation & deletion view.
     * /events/manage/ (officer_event_list): Officer management dashboard with
       live attendee tallies, edit, and delete triggers.
   - Access Control: Enforced via @login_required and @officer_required decorators.

B. RSVP & Attendance Tracking (Member & Shared)
   - Database Model: RSVP model with event (FK), user (FK), status (ChoiceField:
     'GOING', 'NOT_GOING'), and auto_now timestamp. Constrained with
     unique_together = ('event', 'user') so a member can only have one RSVP per event.
   - Business Logic & Capacity Protection:
     * Prevents overbooking: Users cannot RSVP as 'GOING' if event is at capacity.
     * Live counts: Event.confirmed_count, Event.available_spots, and Event.is_full.
   - Views & Endpoints:
     * /events/ (upcoming_events): Public/Member directory showing future events,
       remaining spots, and the user's current RSVP status.
     * /events/<id>/ (event_detail): Comprehensive event view with interactive
       RSVP submission card for members, and a live Attendee Roster table for officers.
     * /events/<id>/rsvp/ (rsvp_event): POST action handling attendance marking.
     * /events/my-rsvps/ (my_rsvps): Member dashboard of personal attendance history.
     * /events/attendance/ (attendance_tracker): Officer overview of all sessions.
   - Access Control: Enforced via @login_required and @member_required decorators.
